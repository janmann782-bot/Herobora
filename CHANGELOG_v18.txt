InfoBox Bot v18 — редактор сторон для битв

- Добавлена кнопка «⚔️ Редактор сторон» для страниц типа «Битва»
- Для каждой из двух сторон можно задать название
- Для каждой стороны можно добавлять до 10 участников
- У каждого участника отдельное имя и необязательный флаг
- Флаги автоматически попадают в battle image roles s1:/s2: и отображаются существующим renderer
- Старые поля «Сторона 1» и «Сторона 2» автоматически подхватываются при первом открытии редактора
- Замена и удаление флагов не оставляет лишние медиафайлы
- При копировании страницы медиа автоматически привязывается к новой копии
